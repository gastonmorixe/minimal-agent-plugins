Show a diff in the `diff -u` format to the user, in ANSI colors. Use it when the diff is the primary content of your response. For a hunk in a longer text, write the `<ma::emit::diff>` tag, then the diff text, then the end tag. The tag has one optional attribute, `title`. Do not put the patch text directly in your response.

The tool gives you the patch text with no change. Only the user sees the colors: added lines are lime green and removed lines are pink.

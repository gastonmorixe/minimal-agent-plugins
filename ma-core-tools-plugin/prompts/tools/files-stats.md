Show the status at this time of the files that the session monitors.

The tool gives the status of the files that the session recorded. To show only the files with one status, set `status` to `present`, `missing` or `changed`. To show all monitored files, do not set `status`. To filter by one file or a directory prefix, use `path`. This tool has read-only access. It does not examine the filesystem, and it does not add files to the monitored files.
